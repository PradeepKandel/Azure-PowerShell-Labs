# Azure-PowerShell-Labs

A collection of practical Azure PowerShell labs designed for Azure administrators and cloud engineers. The labs focus on learning by doing, with step-by-step exercises and sample scripts.

## Topics Covered

- Azure Virtual Machines
- Azure Virtual Networks
- Resource Groups
- Entra ID
- Storage Accounts
- Network Security Groups
- Azure Backup
- Automation Accounts
- Managed Identities
- Azure Monitor
